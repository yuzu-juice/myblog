# MYBLOG

https://yuzu-juice.dev

This is a single-page personal site built with modern web technologies. It introduces who I am, my skills, certifications, and educational background.

## Tech Stack

-   Framework: React
-   Build Tool: Vite
-   Language: TypeScript
-   Styling: Tailwind CSS
-   UI Components: shadcn/ui
-   Icons: Lucide React
-   Linting: ESLint
-   Formatting: Prettier

## Deploy

Deployment is automated via [Coolify](https://coolify.io/). Any push to the `main` branch will trigger a new deployment.
